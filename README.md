# Movie App

A movie discovery web app built using React.

## Features

- Browse movies
- View movie details
- Add movies to your watchlist
- Remove movies from your watchlist
- Separate Home, Movies, Movie Details and Watchlist pages
- Easy navigation using React Router

## Technologies Used

- React
- JavaScript
- React Router
- Redux Toolkit
- CSS
- Vite

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

npm install

5. Then run:

npm run dev

6. Open the local link shown in the terminal.
